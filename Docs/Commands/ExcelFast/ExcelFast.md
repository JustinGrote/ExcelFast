# ExcelFast Module

## Description

ExcelFast is a high-performance PowerShell module for working with Excel files. It provides cmdlets to open, read, write, and manipulate Excel workbooks efficiently. Built on ClosedXML and MiniExcel for fast operations without requiring Microsoft Excel to be installed.

## ExcelFast Cmdlets

### [Get-Workbook](Get-Workbook.md)

Opens an Excel workbook for manipulation and analysis.

### [Import-Workbook](Import-Workbook.md)

Imports data from an Excel workbook, worksheet, or range into PowerShell objects.

### [Export-Workbook](Export-Workbook.md)

Exports PowerShell objects to an Excel workbook.

### [Save-Workbook](Save-Workbook.md)

Saves an Excel workbook to a file.
